# Nova Market Seller

Frontend application for sellers on the Nova Market marketplace.

## Overview

Nova Market Seller is the seller portal of Nova Market, a multi-vendor e-commerce platform.

It will allow sellers to manage their shop, products, orders and other seller-related operations.

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- React i18next
